# XMBookmark (XMB Bookmark Launcher)

PS3（Firmware 3.00時代）の「XMB（クロスメディアバー）」の操作感・視覚効果・サウンドを忠実に再現した、シングルページ構成（HTML5 / CSS3 / Vanilla JavaScript）のWebブックマークランチャー＆メディアアプリケーションです。

---

## 🌟 主な機能と特徴

### 1. XMB特有の「1個ずつ動く時の感触」の完全再現（GPU translate3d & スクロール）
- **ロケットダッシュ＆急ブレーキ物理**:
  - トランジション時間 **`260ms`**、イージング関数 **`cubic-bezier(0.04, 0.88, 0.12, 1.0)`** を適用。
  - 移動キーを押した瞬間に**猛ダッシュで飛び出し、徐々に減速して最後に急ブレーキでピタッと吸着停止する**、XMB特有の快感アニメーション。
  - 横軸カテゴリ・縦軸サブアイテムともに `translate3d(...)` で全アイコンが一斉にスクロール移動。
- **基準交差ポイント（フォーカス原点）**: 画面の左から約 `28%`、上から約 `32%`。
- **交差軸ジャンプギャップ物理**:
  - 選択中の縦アイテムは、横軸カテゴリアイコンの直下（`originY + 110px`）に配置（`scale(1.35)`、白いグロー発光）。
  - **選択アイテムより上（前のインデックス）にある縦アイテムは、横軸のカテゴリバーを飛び越えて「上側」にジャンプ配置**（XMBの最重要視覚特徴）。
  - 選択アイテムより下（次のインデックス）にある縦アイテムは、さらに下へ等間隔に整列。

### 2. ブラウザ・ブックマークランチャー＆メディア機能
- **同一タブ遷移**: URL選択時は同じタブで素早く開き、Webページからブラウザの「戻る」ボタンですぐにXMBookmarkに復帰可能。
- **Favicon（ブックマーク画像）自動取得＆表示**:
  - WebサイトのURL登録時、Google Favicon APIやHTML埋め込みFaviconから高画質ファビコン（64px）を自動取得してアイコン枠に美しく表示。
- **画像サムネイル＆音楽ジャケット（ID3 APIC）抽出**:
  - 画像ファイル登録時はブラウザ内で自動リサイズしたサムネイル画像をアイコンに即時反映。
  - MP3等の音楽ファイル登録時は、純粋なJavaScriptによるID3v2 APICタグパーサーが埋め込みジャケット画像を自動抽出してアイコンとして表示。
- **ブラウザ・ブックマークのインポート (HTML)**:
  - Chrome / Edge / Firefox等の「ブックマークをエクスポート」で書き出した `bookmarks.html` を直接取り込み可能。
  - 検出されたフォルダから「ブックマーク バー」等を指定してインポートでき、サブフォルダごとにXMBの横カテゴリ列として美しく自動展開。
- **初期カテゴリ**:「設定」「カテゴリ１」「カテゴリ２」「カテゴリ３」＋ 右端の「（＋追加）」列。
- **カテゴリ編集メニュー**:
  - 横軸カテゴリアイコンの**長押し（タッチ／マウス）**、**マウス右クリック**、または**ゲームパッドのBボタン**で「カテゴリ編集メニュー」をポップアップ表示。
  - 実行可能操作：
    - **カテゴリの移動**: ◀ 左へ移動 / ▶ 右へ移動（※「設定」列より左へは移動できないよう厳格に保護ガード）。
    - **名前・アイコンの変更**: カテゴリ名およびアイコン種別をモーダルから自由に変更可能。
    - **カテゴリの削除**: カテゴリ列と内部アイテムを一括安全削除。
- **アイテム・ポップアップメニュー（コンテキストメニュー）**:
  - 設定列以外の全アイテムで、**マウス右クリック**、**長押し（タッチ／マウス）**、**Shift+F10**、**ゲームパッドの△/□ボタン**でポップアップメニューを表示。
  - メニュー機能：開く（同じタブ）、URLコピー、タイトルコピー、別のカテゴリへ移動、アイテム編集、アイテム削除。
- **設定列のドキュメント**:
  - **操作マニュアル**: キーボード・ゲームパッド・タッチ操作ガイド。
  - **XMBookmark作成ノート**: 基準交差ポイント物理、猛ダッシュ＆急ブレーキイージング、プロシージャルWeb Audio合成の技術仕様ノート。

### 3. イージーリスニング＆プロシージャルWeb Audioサウンドエンジン
外部音声ファイルに依存せず、Web Audio API (`AudioContext`) により完全プロシージャル合成：
- **イージーリスニングBGM**: 聴いていて心地よいフェンダーローズ調の柔らかなサイン波トーン＋温かいローパスフィルターによるコード進行（Cmaj7 → Am9 → Fmaj7 → Gsus4）と星の煌めきチャイム。
- **移動音**: XMB特有の「カチッ / コッ」という透明感のある硬質クリック音（高周波サイン波＋微小ノイズエンベロープ、減衰35ms）。
- **決定音**: 澄んだクリスタル和音のアルペジオチャイム（ピロッ）。
- **キャンセル音**: 落ち着いた下降トーン（ポッ）。

### 3. PS3 Firmware 3.00 オマージュ背景ビジュアル
- 全画面 `<canvas>` によるマルチレイヤー・シルクリボン波（三次ベジェ曲線による滑らかなうねりと光沢エッジライン）。
- 瞬くスターダスト・パーティクル（星屑の浮遊とTwinkle効果）。
- ナビゲーション操作時にリボンがふわっと揺らめくインパルス・リアクション。
- 6種類のカラーテーマ切り替え（ディープパープル、コズミックブルー、エメラルド、ダークスペース、ルビー、サンセットゴールド）。
- カスタム壁紙（ローカル画像 / URL指定）設定機能。

### 4. マルチ入力システム
- **キーボード**: `▲▼◀▶`（移動）、`Enter` / `Space`（決定）、`Esc` / `Backspace`（戻る）、`Delete`（アイテム削除）。
- **ゲームパッド (Gamepad API)**: D-Pad / 左スティック、初回280ms待機 → 110msリピート間隔、A/Bボタン（決定/戻る）、右上に接続状態インジケータ。
- **タッチ＆マウス**:
  - 画面上下左右のエッジゾーン（▲▼◀▶）タップで1マスずつ移動。
  - 画面上のアイコンを直接タップして選択・決定。
  - スワイプ操作によるフリック移動。

### 5. 階層とアイテム管理
- **URL**: Webリンク登録（新規タブで開く）。
- **ファイル**: ローカルファイル選択（画像・音声・動画・テキストのブラウザ内プレビュー対応）またはパス参照登録。
- **フォルダ**:
  - **XMB内サブフォルダ（仮想階層）**: 決定でXMBの階層を潜り、フォルダ内アイテムを展開（パンくずリスト＆戻る操作）。
  - **ローカルフォルダパス登録**: パスメモ＆クリップボードワンクリックコピー。
- **（＋追加）列**: 横軸の右端から新しいカテゴリ列を自由に追加可能。
- `localStorage` による自動保存、JSON形式でのバックアップ・復元・初期化。

## 🚀 起動方法

### そのままブラウザで開く場合
`index.html` をダブルクリックするか、ブラウザにドラッグ＆ドロップするだけで動作します。

### ローカルサーバーで開く場合（推奨）
PowerShell / ターミナルで本ディレクトリに移動し、以下を実行します：

```bash
# Node.js を使用する場合
npx serve .
# または
node -e "const http=require('http'),fs=require('fs'),path=require('path');http.createServer((req,res)=>{let f=req.url==='/'?'index.html':req.url.slice(1);fs.readFile(path.join(process.cwd(),f),(err,d)=>{if(err){res.writeHead(404);res.end('Not Found');}else{res.writeHead(200);res.end(d);}});}).listen(8080,()=>console.log('http://localhost:8080'));"
```

ブラウザで `http://localhost:8080` を開いてください。

- `index.html` - アプリケーション骨格、HUD、エッジゾーン、モーダル
